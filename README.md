# 8秒前のワタシ — time-echo-game

最大8手の記録を再生する「過去の自分」と協力する、全5ステージのパズルです。
タイトルの「秒」は物語の表現で、実際には操作したときだけ時間が進みます。
通信、音、アカウント登録、パッケージのインストールは不要です。

## はじめて遊ぶ人へ

最初に開くと、短い「操作して覚えよう」が表示されます。黄色いボタンを順に押して、記録・過去の再生・スイッチ・扉・ゴールを実際に体験できます。実際のゲームと同じルールを使う練習専用の盤面です。

- 「スキップ」で、いつでも通常のゲームへ進めます。
- あとから「？」→「操作しながら練習する」で何度でも練習できます。
- 練習を開いても、現在のステージ、記録、扉、戻す履歴は変わりません。
- スキップ・完了はこのブラウザーに保存され、次回は自動表示しません。プライベートブラウズや保存制限、別の公開先では再表示される場合があります。保存が使えなくてもゲームは遊べます。
- 通常のゲームでも、操作パネルの上にステージと状況に合った短い案内が出ます。詳しいヒントは折りたたみを開くと読めます。

今回の変更は練習と案内の追加です。5ステージの配置、動作ルール、クリア判定（`game.mjs`）は変更していません。公開サイトへの反映やGitHubへのPushは別の操作です。

## パソコンで試す

このフォルダーで次のコマンドを実行します（Python 3 が必要です）。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

同じパソコンのブラウザーで、アドレス欄に `http://127.0.0.1:8000` を入力します。
終了するときはターミナルで Ctrl+C を押します。
JavaScript を別ファイルに分けているため、HTMLをダブルクリックする代わりにサーバーを使ってください。

## iPhone の Safari で確認する

GitHub Pages を更新せずに確認できます。

1. 作業用ブランチ `feature/interactive-tutorial` のファイルを自分のパソコンに用意します。今回の変更はクラウド内のローカルブランチにあり、GitHubにはまだ push していません。
2. パソコンと iPhone を同じ信頼できる Wi-Fi につなぎます。
3. パソコンでこのフォルダーを開き、`python3 -m http.server 8000 --bind 0.0.0.0` を実行します。Windows では `python3` の代わりに `py` を使える場合があります。
4. パソコンのネットワーク設定で「ローカルIPアドレス」を確認します。iPhone の Safari のアドレス欄に `http://パソコンのIPアドレス:8000` と入力します。クラウド環境の localhost は iPhone から直接開けません。
5. 縦向きで、盤面と全操作ボタンが見えるか、各ボタンを押し間違えず使えるか、「？」とヒントを開閉できるか確認します。Safari のアドレスバーを表示した状態でも確認してください。
6. 下の解答例で全ステージを遊び、扉の残り手数と「1手戻す」を確認します。終わったらパソコン側で Ctrl+C を押します。

接続できない場合は、パソコンのファイアウォールや Wi-Fi の端末間通信制限を確認してください。インターネットへのポート開放や、ルーターの転送設定は不要です。

## ルール

- 「記録を始める」→ 移動・待つを最大8手記録 →「再生して協力」の順に操作します。
- 記録中は扉を通れません。再生開始時はふたりともスタートに戻ります。
- 現在表示されている扉の状態であなたが行動し、その後に過去が1手再生します。スイッチによる扉の変化は次の行動から使えます。
- 壁や閉じた扉への移動は失敗し、時間は進みません。「待つ」はその場で時間を1手進めます。
- 記録後の過去は最終位置に留まります。ただし、留まっているだけでは「待つ」を再生したことにはなりません。
- 過去は「過」スイッチを、あなたは「今」スイッチを担当します。「待」スイッチは過去がそこで「待つ」を再生したときだけ反応します。
- 時間制限付きの扉は、開いた後の表示手数ぶんの行動で通れます。上に立っている間に閉じても、そのマスから出ることはできます。
- 「1手戻す」は記録中・再生中・クリア直後に使えます。再生中は扉や過去も一緒に戻ります。
- キーボードは矢印で移動、Wキーで待ちます。ボタンなどにフォーカスがない場合はスペースでも待てます。
- 「やり直す」は現在のステージを初期状態に戻します。ブラウザーを再読み込みするとステージ1に戻ります。

## 5つの異なる仕掛け

| ステージ | 攻略の鍵 |
| --- | --- |
| 1 はじめての協力 | 過去をスイッチに残して扉を開ける |
| 2 止まることも記憶 | スイッチの上で「待つ」を記録する |
| 3 遅れて届く合図 | 記録の出だしを遅らせ、2手だけ開く扉に間に合わせる |
| 4 ふたりの合図 | 過去と現在で別々のスイッチを同時に踏む |
| 5 8手の約束 | 待つと開く3手制限の扉を通り、その後ふたりで別の扉を開く |

## 開発とテスト

- `game.mjs`: 盤面データと1手のルール。画面とは独立しています。
- `app.mjs`: 表示、タッチ・キーボード操作、戻す機能。
- `tutorial.mjs`: ゲームと状態を共有しない体験型チュートリアル。
- `style.css`: 画面の高さに応じた盤面と、44px以上の操作ボタン。
- `index.html`: 画面の構成と遊び方。

Node.js 18以降（今回の検証は24）でルールのテストを実行できます。追加パッケージは不要です。

```sh
node --test tests/game.test.mjs
```

クラウド環境に用意されている Playwright と Chromium を使う画面テスト：

```sh
node tests/browser.cjs
```

画面テストは専用のローカルサーバーを一時的に起動し、終了時に停止します。別のPCで動かす場合は Playwright と Chromium の準備が必要です。Chromium の場所は `CHROMIUM_PATH` で指定できます。

画面サイズ320×568、375×667、390×844、430×932で、初回練習・完了・スキップ・再表示・ゲーム途中からの復帰、および全ステージのタッチ操作、クリア、戻す、リセット、ヘルプ、主要ボタンの画面内配置を検証します。保存機能が使えない場合とEscapeキーで閉じる操作も検証します。これは Chromium によるサイズ再現であり、iPhone実機のSafari検証とは別です。
